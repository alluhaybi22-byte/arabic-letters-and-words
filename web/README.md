# Tibyan — تِبْيان لقياس مدى الإتقان

مصدر نسخة الويب من برنامج الاختبار التشخيصي الشفوي لمادة لغتي الجميلة للصفوف الأولية.

أُخذ المصدر من النسخة المنشورة `1791836976942` في 19 أكتوبر 2026، ثم أضيف تجهيز الحفظ في Google Drive والنسخ الاحتياطي الكامل في الإصدار `1.4.1`.

## التشغيل

```sh
npm ci
npm run dev
```

للبناء والفحص:

```sh
npm test
npm run build
npx tsc --noEmit
```

مجلد `dist` هو ناتج البناء؛ لا يُرفع إلى المستودع. الصفوف والنتائج بيانات مستخدم محلية، ولا تُضمّن في المصدر أو التوزيع.

## حفظ البيانات

- مفاتيح التخزين المحلية السابقة محفوظة كما هي؛ لا يحدث استيراد من نسخة Windows أو أي مستودع آخر تلقائيًا.
- زر **Google Drive والنسخ الاحتياطي** يتيح تنزيل نسخة JSON كاملة واستعادتها، مع التحقق من الصيغة وإنشاء نسخة استرجاع محلية قبل الاستبدال.
- أُضيف معرّف Google OAuth العام الذي أعدّه المالك. يبقى تسجيل الدخول والموافقة من نافذة Google لإتمام الربط؛ لم يُؤكَّد رفع فعلي إلى الحساب بعد. راجع [GOOGLE-DRIVE.md](GOOGLE-DRIVE.md).
- بعد نجاح الربط تُحفظ التغييرات تلقائيًا أثناء فتح التطبيق، في ملف مستقل لكل جهاز. لا توجد مزامنة دمج تلقائية بين جهازين؛ تُختار النسخة المطلوبة للاستعادة.
- لا يُرفع أي رمز دخول أو إعداد حساب ضمن النسخة الاحتياطية. لا تُخزّن بيانات الطلاب في GitHub أو على خادم AppDeploy.

## حدود التحقق

تُختبر دورة تصدير/استعادة الصفوف والنتائج والمسودة، ومنع الملفات غير الصالحة، وفشل التخزين والتراجع عن الاستعادة. يُفحص البناء وواجهة النسخ الاحتياطي. تسجيل الدخول الحقيقي ورفع ملف إلى حساب Google Drive حقيقي يتطلبان إعداد Google Cloud وموافقة المالك، ولم يُختبرا قبل توفيرهما.
