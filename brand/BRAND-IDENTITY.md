# مساحة القراءة — تكييف واجهة Figma Make للنسخة 1.3

## الفكرة

مساحة عمل عربية هادئة للمعلم. واجهة فاتحة بدرجات عاجية وبنفسجية، ومسرح قراءة أبيض يعطي الحرف والكلمة والجملة أكبر وزن بصري أثناء الاختبار. العلامة المختصرة «لُ» تستخدم بجانب اسم التطبيق.

## القيم المشتركة

| الدور | القيمة |
| --- | --- |
| الخلفية | `#F5F1EB` |
| السطح | `#FFFFFF` |
| النص | `#24243A` |
| الأساسي | `#4F46E5` مع التدرج إلى `#7C3AED` للإجراء الرئيسي |
| النجاح | `#059669` |
| التنبيه | `#D97706` |
| الخطأ | `#DC3549` |
| المعلومات | `#3D69A5` |
| الحدود | `#E7E5E4` |

القيم معرفة في CSS كمتغيرات `--ui-*`. حالات النجاح والخطأ تظهر بكلمة ورمز إلى جانب اللون. توزع شاشة الإعداد مساحة العمل على تنقل مستقل، كشف طلاب حي، ومحتوى الاختبار.

## الخط والاتجاه

- **Arial** في التطبيق ومحتوى القراءة والتقارير المطبوعة.
- RTL من جذر المستند. المؤقت يعرض أرقامه باتجاه LTR لثبات قراءتها.
- الحركات والتنوين جزء من محتوى القراءة، مع ارتفاع سطر ومساحة رأسية تكفي لظهورها.
- نموذج Figma Make يستخدم Cairo؛ النسخة التشغيلية تستعمل Arial كما طُلب، دون اعتماد على خطوط الإنترنت.

## الملفات

- `logo.svg`: علامة «لُ» مصغرة.
- `icon.png`: أيقونة نافذة Electron.
- `icon.ico`: مصدر أيقونة Windows للبناء اللاحق.

النسخة المحمولة الحالية تعيد استخدام غلاف Electron التجريبي السابق؛ أيقونة ملف EXE المضمّنة في الغلاف قد تبقى من النسخة السابقة، وتظهر العلامة الجديدة داخل التطبيق وعلى النافذة.
