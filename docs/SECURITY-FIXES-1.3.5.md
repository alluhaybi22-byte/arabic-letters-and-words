# إصلاحات الأمان — النسخة المحلية 1.3.5

تاريخ التحقق: 2026-10-05. هذه تغييرات محلية فوق تعديلات معاينة الطباعة
المحفوظة سابقًا، وليست إصدارًا منشورًا أو مثبتًا معتمدًا على Windows.

## الإصلاحات المنفذة

- استيراد Office: رفض الملفات الأكبر من 25 MiB قبل قراءتها عندما يتوفر الحجم،
  والتحقق من الحجم الفعلي بعد القراءة. حتى 512 مدخلًا، و8 MiB لكل XML، و32 MiB
  إجمالًا، ونسبة توسع قصوى 250 مع سماحية 64 KiB، ومهلة 15 ثانية لفك الضغط.
  تتوقف القراءة المتدفقة قبل تجاوز الحد، حتى إذا زوّر الملف الحجم المعلن.
  تُقرأ مكونات XML المستخدمة فقط ولا تُستخرج أسماء الأرشيف كمسارات ملفات.
- استيراد PDF: حد حجم الإدخال، وحد 300 صفحة، وحد 16 ميغابكسل لصورة OCR،
  وتعطيل تقييم JavaScript في PDF.js وتحرير مستند PDF بعد الاستيراد.
- XLSX: رفض عناوين أعمدة تتجاوز الحد القياسي 16384، لمنع مصفوفات متناثرة ضخمة.
- متابعة إصلاح PDF: تجميع الصفوف بفهرس مكاني بدل البحث في جميع الصفوف السابقة،
  مع الحفاظ على هامش المحاذاة 3 وحدات واختيار أول صف مطابق. قراءة عناصر النص
  متدفقة بحد 20000 عنصر و1 MiB نص لكل صفحة، و200000 عنصر و8 MiB نص إجمالًا،
  وحد 256 عمودًا للتخطيط. مهلة الاستيراد 3 دقائق وزر إلغاء يوقف عامل PDF وOCR
  والرسم وقارئ النص. لا يُقتطع كشف بصمت؛ يظهر رفض واضح عند تجاوز الحدود.
  ينتقل التنفيذ بين الصفحات إلى دورة أحداث الواجهة لتظل قابلة للاستجابة.
- عرض النتائج: تهريب درجات البنود وقيم الملخص والنسب ومعرّفات ملف الطالب عند
  إدراجها في HTML. لا يعيد العرض كتابة السجل المخزن، ولا يغير التقييم السليم.
- CSP: شيفرة الواجهة في renderer.js بدل السكربت المضمن. لا unsafe-inline أو
  unsafe-eval للسكربتات. السماح بـ WASM والعمال المحليين الضروريين لـ OCR فقط،
  مع منع الإطارات والكائنات والاتصال الخارجي من صفحات الواجهة. تبقى الأنماط
  المضمنة مسموحة للحفاظ على التصميم. التحديث يستخدم عملية Node وليس اتصال الواجهة.
- IPC الطباعة: التحقق من النافذة المسجلة والإطار الرئيسي وعنوان الملف الدقيق
  لجميع عمليات المعاينة والطابعات والطباعة وحفظ PDF. منع فتح صفحات PDF أو نوافذ
  عشوائية؛ التقارير تستخدم قناة المعاينة المخصصة. رفض أذونات المتصفح غير المطلوبة.
- تقارير مؤقتة: التخزين في مجلد print-previews داخل ملف تعريف التطبيق، والحذف عند
  إغلاق المعاينة وتنظيف بقايا هذا المجلد عند التشغيل التالي. قفل نسخة واحدة يمنع
  تنظيف معاينات نسخة أخرى حية. لا تُمس سجلات الطلاب أو ملفات تعريف النسخ السابقة.
  لا يشمل هذا التنظيف مجلدات Temp القديمة خارج المساحة الجديدة، ولا يضمن المحو الآمن.

## الاختبارات التي نجحت محليًا

- npm run verify.
- npm test: اختبارات التقييم والمؤقت والاستئناف والاستيراد وسجل الصفوف والمحاولات،
  والطباعة وPDF والتحديث وحفظ البيانات، بالإضافة إلى اختبارات أمان جديدة.
- الملف الضار المضغوط ذو الحجم الحقيقي المعلن، والملف الذي يزوّر الحجم، كلاهما
  مرفوضان. حمولة الاختبار محدودة بـ 2 MiB وليست تجربة استنزاف ذاكرة.
- الملفات الطبيعية DOCX/XLSX، متعددة الأعمدة والأوراق والأسماء المتكررة، تظل ناجحة.
- سجلات محلية معدّلة بوسوم HTML تُعرض مهربة دون تغيير البايتات المحفوظة.
- طلبات الطباعة من إطار/عنوان غير معتمد تُرفض. تنظيف معاينة متروكة لا يحذف سجلات
  الطلاب أو الملفات غير التابعة، ويرفض مسارًا رمزيًا غير آمن.
- مقارنة تجميع PDF القديم والجديد على إحداثيات عشوائية وحالات التداخل تطابق
  النتائج. لم يعد تجميع 2000 صف يفحص نحو مليوني زوج. اختبارات القراءة المتدفقة
  والحدود والإلغاء وتنظيف القارئ نجحت، وكذلك إلغاء الواجهة ومهلة عامل PDF ورفض
  الاستيراد المتزامن واستعادة الأزرار دون تغيير بايتات الصفوف والنتائج المحفوظة.
- npm audit --json، وnpm audit --omit=dev --json: لم تُبلغ الخدمة عن ثغرات معروفة
  في الاعتماديات المحددة في ملف القفل وقت الفحص. لا يعد ذلك ضمانًا شاملًا للأمان.
- git diff --check.

## حدود التحقق والخطوات المتبقية

أُعد اختبار تكامل فعلي لـ CSP وPDF وOCR في tests/security-ui.cjs، لكن تشغيل
Electron محليًا توقف لأن البيئة تمنع socket الخاص بقفل النسخة الواحدة
(Operation not permitted). لم يُتحايل على هذا القيد. أضيفت اختبارات CSP وOCR
أيضًا إلى اختبارات Windows القائمة، ولم تُنفذ على Windows في هذه الجولة.
لا تُعتبر واجهة المعاينة أو OCR أو الطابعة معتمدة تشغيليًا بعد هذه التغييرات
قبل اجتياز اختبارات النسخة المثبتة على Windows.

التوقيع بشهادة ناشر موثوقة لا يزال يحتاج إعداد جهة التوقيع؛ لم تُضف أسرار أو
شهادة ذاتية ولم تُعطل آلية تحقق التحديث. قناة التحديث العامة لم تتغير ولم
تُفعّل قناة خاصة غير مصادقة. المسودة وحدها ليست قناة تحديث خاصة.

لم يُنشأ Commit أو Push أو Release، ولم تُغير خصوصية المستودع أو صلاحياته،
ولم تُحذف مخرجات البناء العامة السابقة. إخراج المثبت المشفر المعد سابقًا
ما زال محفوظًا ضمن التعديلات المحلية، وليس تحديثًا خاصًا جاهزًا داخل التطبيق.
