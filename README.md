# تطبيق تقييم الحروف العربية لسطح المكتب

تغلف هذه الملفات صفحة `index.html` الحالية في تطبيق Windows 11 باستخدام Electron، مع تقييم الحروف، سجل النتائج، تقارير Word، واستيراد كشوف الطلاب.

## ما يتضمنه الإصدار الحالي

- واجهة عربية متجاوبة باتجاه من اليمين إلى اليسار، مع زر ثابت للعودة إلى الصفحة الرئيسية من كل شاشة فرعية.
- أربعة مستويات للتقييم، بخط النسخ الواضح، مع استخدام `أ` و`هـ` في المستوى الأول وإزالة السكون من المستويين الثاني والثالث.
- استيراد كشوف PDF وDOCX وXLSX، ثم مراجعة الأسماء بالترتيب قبل حفظ الكشف.
- كشوف مستقلة متعددة، ومعرف داخلي فريد لكل كشف وكل طالب وكل تقييم.
- ملف زمني لكل طالب يعرض جميع تقييماته وتفاصيل الحروف المتقنة والتي تحتاج إلى تدريب.
- حفظ تلقائي لكل تقييم جديد دون استبدال السجل السابق، مع الحفاظ على البيانات المحلية القديمة عند التحديث.

## التشغيل والبناء

1. ثبّت [Node.js LTS](https://nodejs.org/) على Windows ثم افتح PowerShell في مجلد المشروع.
2. نفّذ `npm install`.
3. للتشغيل أثناء التطوير نفّذ `npm start`.
4. لإنشاء مثبت Windows بصيغة EXE نفّذ `npm run dist`.

بعد نجاح البناء يكون ملف المثبّت في:

```text
release\Arabic-Letter-Assessment-Setup-1.0.0.exe
```

## ملاحظات

- هذا المجلد هو **نسخة المصدر القابلة للتعديل**. ملفات الواجهة ومنطق التطبيق موجودة في `index.html`، ونقطة دخول Electron في `main.js`، وإعدادات الاعتمادات والبناء في `package.json`.
- أصول PDF وOCR المحلية موجودة في `vendor\`، وملفات الخطط العلاجية في `plans\`. يجب الإبقاء عليهما عند نقل المستودع أو بناء التطبيق.
- لا تُضاف `node_modules\` أو `release\` إلى المستودع؛ يجري إنشاؤهما تلقائيًا عبر `npm install` و`npm run dist`.
- يحتاج التطبيق اتصال إنترنت عند التشغيل الأولي لتحميل مكتبات قراءة وإنشاء ملفات Word وخطوط الواجهة، تمامًا كما في صفحة الويب الأصلية.
- ملفات DOCX التي ينشئها التطبيق تُنزَّل عبر Chromium المدمج وفق إعداد تنزيلات Windows المعتاد.
- لاستيراد كشف الأسماء، اكتب **اسم الكشف أو الصف** ثم اضغط **استيراد كشف PDF أو Word أو Excel** واختر PDF أو DOCX أو XLSX. يدعم التطبيق كشوف PDF النصية والمصورة (باستخدام OCR عربي مضمّن) وملفات Word وExcel، ويحافظ على ترتيب الأسماء ويعرضها للمراجعة قبل الاعتماد.
- يُحفظ كل كشف مستقلًا، ويمكن اختياره من قائمة **الكشف النشط** دون فقدان حالة الطلاب أو الغياب في أي كشف آخر. لكل طالب داخل الكشف معرف مستقل وسجل تقييمات متراكم.
- بعد حفظ نتيجة الطالب، اضغط **اختبار الطالب التالي** للانتقال تلقائيًا إلى الاسم التالي في الكشف. تُحفظ قائمة الانتظار والموضع الحالي محليًا حتى بعد إغلاق التطبيق.
